# lib3d — 3D scenes for Bang Motion

`bm3d.js`: deterministic three.js presets (terrain, globe, crystal, galaxy, bars, water) shared by HyperFrames (`"three"` field on a scene)
and Lemo native (`lemo-scene.js` as a custom scene). three.js (MIT) is copied next to these files at build time from `lemo/node_modules/three`.
Written with the guides in `.claude/skills/threejs-*` (MIT, © 2026 CloudAI-X, https://github.com/cloudai-x/threejs-skills;
licence: `.claude/skills/LICENSE-threejs-skills-MIT.txt`). Usage: `.claude/skills/bang-motion/SKILL.md` → "3D scenes".
